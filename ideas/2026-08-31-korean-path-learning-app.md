# Korean Path — Phased Language Learning App

**Date:** 2026-08-31  
**Status:** Raw Brain Dump

## The Core Idea

A language learning app that teaches Korean through finite phases with clear exit criteria — the opposite of endless Duolingo grinding. Built for adult learners who already watch K-dramas and want a structured path to real conversation.

## Why Now?

User (40) wants to learn Korean, motivated by K-drama watching. Frustrated with gamified apps that never end. Asked to turn the recommended learning path into an actual app.

## Initial Thoughts

- Anti-Duolingo philosophy: phases, not levels; milestones, not streaks
- Leverage existing free resources (TTMIK, GO! Billy Korean) — app is the guide/coach, not the content creator
- Drama phrase miner: capture vocabulary from shows you watch
- Weekly routine built in (M/W/F study, T/Th speaking)
- Speaking is a first-class feature (tutor reminders, conversation prompts)
- Start Korean-only; architecture allows other languages later
- MVP: web app, localStorage persistence, no backend
