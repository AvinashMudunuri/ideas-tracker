# Build a Personal Knowledge Graph

**Date:** 2026-07-04  
**Status:** Raw Brain Dump

---

## The Core Idea

Create a visual knowledge graph that connects ideas, notes, and projects so I can see relationships and patterns over time.

---

## Why Now?

I keep losing context when switching between projects. Ideas sit in isolation when they could inform each other.

---

## Initial Thoughts

- Should integrate with this ideas tracker
- Need bidirectional linking between documents
- Could use graph visualization library
- Maybe start simple with just markdown links and generate graph from that
- Tags could be nodes too
- Time-based view would be interesting

---

## Questions / Unknowns

- Export format?
