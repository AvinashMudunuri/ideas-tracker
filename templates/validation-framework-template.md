# Validation Framework for [Idea Name]

**Purpose:** Quick reality checks before investing significant time in building.

---

## 1. Quick Reality Check (15 minutes)

**Test existing solutions:**
- [ ] Try [Competitor A] for your actual use case
- [ ] Try [Competitor B] for your actual use case
- [ ] Does it solve the problem or leave you frustrated?
- [ ] What specific thing is missing or broken?

**Decision point:** If existing tools are 80%+ good → just use them. If clear gap → continue.

---

## 2. Talk to Real Users (30 minutes)

**Find 3 people who match your target user:**
- [ ] Person 1: [Name/description]
- [ ] Person 2: [Name/description]  
- [ ] Person 3: [Name/description]

**Ask:**
- "How do you currently [do the thing your idea solves]?"
- "What's frustrating about that?"
- "Would you pay/spend time on a better solution?"

**Red flag:** If they don't naturally mention the problem, demand is weak.

---

## 3. Feasibility Sanity Check (30 minutes)

**Technical:**
- [ ] Is the core technical challenge solvable? (quick spike/prototype)
- [ ] Are there APIs, data sources, or tools available?
- [ ] Can you build an MVP in [timeframe you're willing to commit]?

**Legal/Ethical:**
- [ ] Any obvious legal blockers? (ToS violations, licensing, regulations)
- [ ] Ethical concerns that would make this uncomfortable?

**Resources:**
- [ ] Do you have the skills needed or can learn them quickly?
- [ ] Any critical dependencies on others? (funding, partnerships, data access)

---

## 4. Build or Use? (15 minutes)

**Answer honestly:**

| Question | Answer |
|----------|--------|
| Is this a real problem I/others have frequently? | Yes/No |
| Do existing solutions leave a significant gap? | Yes/No |
| Can I build something meaningfully better? | Yes/No |
| Am I willing to commit [X weeks/months] to this? | Yes/No |
| Is the juice worth the squeeze? | Yes/No |

**Decision:**
- **4-5 Yes:** Synthesize and move to Ready to Start
- **2-3 Yes:** Needs more thinking or scope reduction
- **0-1 Yes:** Archive this idea, move on

---

## Total Time: ~90 minutes

If you're not willing to spend 90 minutes validating, you're probably not excited enough about the idea.
